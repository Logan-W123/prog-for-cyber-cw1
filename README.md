## Overview
This repository is my Coursework 1 portfolio for COMP08101 Programming for Cyber Security. Each exercise is stored in its own Git branch with its Python code, README, LICENSE and test screenshots.

## Exercises and Branches

| Task | Branch | Description |
|---|---|---|
| 1 | `security-tool` | Menu-driven security tool with login, event counter, brute-force simulation and login authentication |
| 2 | `security-event-logger` | Logs every login attempt with an event ID, username, IP address, event type and timestamp |
| 3 | `ip-address-validator` | Checks whether an entered IP address has a valid IPv4 format |
| 4 | `security-incident-manager` | Stores and updates a security incident using a dictionary |
| 5 | `cyber-security-utilities` | Reusable module for password checks, IP checks and strong password generation |

## How to View a Branch
Select a branch from the branch dropdown on GitHub, or run:
```
git clone https://github.com/Logan-W123/prog-for-cyber-cw1.git
cd prog-for-cyber-cw1
git switch security-tool
```
