## What the Program Does
Asks the user for an IP address and uses the `validate_ip()` function to check its format. The address must have exactly three dots and four numbers, each between 0 and 255. Extra spaces are removed first. The program then displays whether the IP address is valid or invalid.

## How to Run
```
python ip_address_validator.py
```
