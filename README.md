## What the Program Does
The code is split into two files:
- **`security_tools.py`** – a module with three reusable functions: one checks a password is strong, one checks the format of an IP address, and one generates a strong random password of 10 to 16 characters.
- **`main.py`** – imports the module, asks the user for a password and an IP address, displays whether each is valid and suggests a strong password if the entered one is weak.

## How to Run
Keep both files in the same folder, then run:
```
python main.py
```
