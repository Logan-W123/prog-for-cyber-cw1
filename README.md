**Name:** Logan Ward
**Campus:** New College Lanarkshire

## What the Program Does
Stores a security incident in a dictionary (username, IP address, event type and risk level). It displays the username and IP address, adds a status field, updates the risk level, removes a field, then displays the remaining keys and values and the total number of key-value pairs.

## How to Run
```
python security_incident_manager.py
```
