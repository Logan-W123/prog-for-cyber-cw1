## What the Program Does
The user must log in before using the tool. After logging in, a menu lets them choose:
1. **Security Event Counter** – asks for a password 10 times, counts correct and incorrect attempts and raises an alert if more than 50% are incorrect.
2. **Brute-Force Simulation** – lets the user guess a password until it is correct or the maximum attempts are reached.
3. **Login Authentication** – checks a username and password, allowing three attempts before the account is frozen for 24 hours.
4. **Exit** – closes the program.

## How to Run
```
python security_tool.py
```
